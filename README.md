# TriGemini – Gemini Chrome Extension

TriGemini is a Chrome Extension that brings the **Gemini Nano** model directly into your browser.  
It provides **fast, offline, and efficient responses** right inside Chrome.

## ✨ Features
- 🚀 **Instant responses** – quick answers without delay  
- 🧩 **Seamless integration** – works with Chrome’s built-in Gemini Nano  
- 📶 **Offline support** – use Gemini Nano even without internet  
- ⚡ **Hotkey access** – press `Ctrl/Command + Shift + Y` to open  

---

## 📖 Installation

1. Make sure you are using **Chrome 127 or higher**  
2. Open `chrome://flags`  
3. Search for **Prompt API for Gemini Nano** and set it to **Enabled**  
4. Restart Chrome  
5. Install TriGemini directly from the **[Chrome Web Store](https://chromewebstore.google.com/detail/gemini-chrome-extension/fnnibnhiaepgmioomkknpcbomaogkdhn?authuser=0&hl=zh-TW)**  

---

## 🚀 Usage
- Click the extension icon in Chrome toolbar  
- Or press `Ctrl/Command + Shift + Y` to chat with Gemini Nano
